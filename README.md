### Chess game with web interface

#### Disclaimer
This is just a fun little project for my own learning. I am a beginner, so please don't be too critical when looking at my code. If you have any recommendations, modifications or tips, do not hesitate to contact me.
#### Description
The goal of this project is to build a chess game in python, without using any libraries like python-chess. The python code is connected to a frontend in HTML/CSS/JS using flask.
#### Use of AI
I tried to avoid using LLMs too much. Since I am not very good with JavaScript, I used some ChatGPT to help me fix some errors and to write some of the code. However, since the goal of this project is to learn, I made sure to understand every single line of code.
